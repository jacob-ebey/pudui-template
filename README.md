# pudui

<img src="https://unpkg.com/pudui/assets/mascot.svg" alt="Pudui mascot, a tiny deer." width="120" height="120" />

A [Remix](https://remix.run) starter template built with
[Vite Plus](https://vite.plus), [Tailwind CSS](https://tailwindcss.com) and
[Pudui](https://pudui.dev).

## Getting Started

```bash
vp install
vp check
vp dev
```
